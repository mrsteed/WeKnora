## 1. 这是什么

一句话：**把公司文档变成一个能秒回、还带出处的大脑。**

- 你问一个问题，系统从你有权访问的知识库里**检索相关原文**，再让大模型**基于原文生成答案**；
- 答案里的关键内容都带**引用角标**，点一下就能看到原文长什么样——判断答案是不是"编的"，看这里就够了；
- 复杂问题（跨文档对比、要查最新行情、要算数）可以切换**智能推理**模式，系统会自己拆步骤、多轮检索、联网搜索，并展示每一步的推理与工具调用过程。

你能用哪些知识库，由空间管理员分配。你看到的知识库列表 = 你有权使用的知识库。

## 2. 登录与界面认识

### 2.1 登录

1. 浏览器打开公司给的内脑地址（如 `http://intranet.example.com`）；
2. 输入邮箱 + 密码（首次账号由 IT/管理员邀请开通）；
3. 登录后进入你所在的工作空间（空间管理员会把你分到一个或几个空间，多空间用户可在左上角切换）。

> 若使用企业单点登录（OIDC），会跳转到公司统一认证页完成登录，无需单独记密码。

### 2.2 界面认识（登录后主界面）

```
┌──────────────────────────────────────────────────────────┐
│  顶栏：空间切换 / 搜索 / 通知 / 头像（个人设置）           │
├──────────────┬───────────────────────────────────────────┤
│              │                                           │
│  左侧导航    │            问答主区域                     │
│  · 智能对话  │  ┌─────────────────────────────────────┐  │
│  · 知识库    │  │  模式切换：[快速问答] [智能推理]      │  │
│  · 智能体    │  │  知识库选择（可多选）                 │  │
│  · Wiki     │  │  [输入框 + 附件按钮 + 联网开关]      │  │
│  · 会话记录  │  └─────────────────────────────────────┘  │
│              │                                           │
└──────────────┴───────────────────────────────────────────┘
```

| 区域 | 内容 |
|------|------|
| **智能对话** | 日常提问入口（最常用的页面） |
| **知识库** | 你有权访问的所有知识库，可浏览文件、看标签 |
| **智能体** | 可用的 Agent 列表（预设好的问答角色，见 §5.3） |
| **Wiki** | 知识库自动生成的百科页面（若该库开启了 Wiki） |
| **会话** | 你的历史对话列表，按渠道分组（网页 / IM / API） |

## 3. 提问：最常用的一个动作

以"网页快速查一份制度文档"为例：

1. 进入**智能对话**；
2. 在输入框上方**选择知识库**（可多选，限定系统去哪些库里找答案）；
3. 输入问题，回车。例如：*"差旅住宿费的标准是多少？北京和外地有区别吗？"*
4. 回答生成前会有一条**进度条**显示当前阶段：
   `解析附件 → 检索文档 → 联网（若开）→ 生成回答`
5. 回答正文中**数字角标**（如 ³）即引用来源，点击跳转到原文分块；右侧**引用面板**列出本轮全部来源，便于逐条核对。
6. 回答下方通常有**追问建议**，点一下即可继续深入。

> **提问前可选项（输入框附近的开关/按钮）**
>
> | 操作 | 用途 |
> |------|------|
> | **知识库多选** | 限定检索范围。选得越准，答案越贴题 |
> | **@提及文档** | 让本轮重点参考某几份具体文件（输入 @ 后选择） |
> | **上传图片/附件** | 临时分析一份文件（不入库，详见 §6） |
> | **开/关联网搜索** | 需要查最新资讯时打开；不需要就关着，省时间 |
> | **@MCP / @技能** | 指定使用某个外部工具或技能（进阶功能，见下） |

> 若管理员为你建好了专属"智能体"（如"制度问答助手"），也可以直接在**智能体**页进入该智能体的对话，知识库范围已经配好，不用自己选。

## 4. 怎么问能得到更好的答案

系统不是万能的，**问法**直接决定答案质量。几条经验：

| 问法 | 效果 |
|------|------|
| **一次只问一件事** | "A 报销流程是什么？"比"报销怎么报、发票要几张、多久到账？"回答更聚焦 |
| **给上下文** | 说清楚背景："我在北京，出差去上海住了两天酒店，该按哪个标准？"比"酒店标准多少"准得多 |
| **点名具体文档** | 用 `@文档名` 让回答只以那份文件为准；避免"全公司制度打架时它答了另一份" |
| **复杂问题拆步骤** | "先总结这份合同的付款节点，再对比那份合同的同类条款" |
| **不满意就换模式** | 快速问答答得粗，切**智能推理**让它再想一轮（见 §5） |
| **答案错了就点引用** | 先看引用原文对不对；若引用都对但答案不对，追问"依据第 X 段再解释一下" |

### 答案不满意时的三种"再问一步"

1. **补充条件**："只看 2025 年之后的规定，重新回答。"
2. **指定文档**："@员工手册2025 版 重新回答。"
3. **升级模式**：切换到**智能推理**重问一遍（适合需要推理/对比/跨库总结的问题）。

## 5. 两种问答模式：快速问答 vs 智能推理

顶部两个按钮，切换的是"思考深度"。

### 5.1 快速问答（默认，快）

- 流程：**一次检索 → 一次生成**
- 适合：**事实性提问**，答案明确存在某份文档里（"XX 的标准是多少？"、"XX 流程的入口在哪？"）
- 速度：秒级；成本：低

### 5.2 智能推理（Agent，慢但强）

- 流程：**多轮"想一步、查一步"**——自己决定查几份文档、要不要联网、要不要跑 SQL 算数、要不要调外部工具
- 界面里能看到**思考过程**（可折叠）和**每一步工具调用记录**，透明可信
- 适合：
  - 跨多个文档的对比（"对比这三份合同的付款条款"）
  - 需要实时信息（"最近 3 个月 XX 法规有什么变化？"——自动联网）
  - 数据分析（丢 Excel 问"哪个部门超预算？"——内置 DuckDB 跑 SQL，见 §5.3）
  - 长流程合规检查（"这份方案符合公司 XX 规范吗？"）
- 代价：慢一些（几十秒到几分钟），Token 消耗更高

### 5.3 智能体（预设好的 Agent 角色）

管理员或团队可以**预先配置好一个 Agent**：固定用哪个模型、查哪些知识库、能不能联网、挂哪些工具、甚至用什么口吻说话。对你来说，它就是一个"入口更快、回答更稳定"的对话窗口。

常见的内置/预置 Agent：

| Agent | 你能用它干什么 |
|-------|--------------|
| **快速问答助手** | 日常事实性提问（默认） |
| **智能推理助手** | 复杂问题、跨文档对比、联网调研 |
| **数据分析助手** | 丢 CSV/Excel 进去问统计问题（SQL 级） |
| **Wiki 研究员** | 在知识库自动生成的 Wiki 上追问、深挖 |

> 你不必自己配置 Agent。需要定制时联系管理员（配置项包括模型、知识库范围、提示词、工具、联网开关等，见《产品手册》04 章）。

## 6. 带着文件来问（临时附件）

有些资料**还没入库**（外部文件、草稿、一份临时合同），不必麻烦管理员建库，直接丢进去问：

1. 对话输入框左侧**上传按钮** → 选文件（图片或文档）；
2. 文件只属于**当前会话**，异步解析后参与本轮问答；
3. **不会进入正式知识库**，也**不会出现在知识库列表**；
4. 会话默认 24 小时后自动清理该附件（不会长期留存）。

典型用法：

- *"看一下这份合同的付款条款"*（丢一份 PDF）
- *"这张架构图讲了什么"*（丢一张图片，走视觉模型理解）
- *"帮我把这份 Excel 的各部门费用做个汇总"*（配数据分析 Agent 时，直接跑 SQL）

> **注意**：扫描件/图片需要系统配置了视觉模型（VLM）才能读懂；若提示"未配置视觉模型"，说明当前环境只支持纯文本——换管理员配置即可。

## 7. 答案的可信度：引用与来源

**引用是判断答案可信度的第一依据。**

### 7.1 两种引用展示

| 展示位置 | 内容 |
|---------|------|
| **正文数字角标**（如 ³） | 回答中该论断的来源，点击直接跳转到原文分块（该分块会高亮） |
| **右侧引用面板** | 本轮**全部**来源的列表：知识库来源 / 网络搜索来源 / Wiki 来源，可展开看摘要 |

> 正文里看不到的角标，不代表"没有来源"——面板里依然完整列出。若管理员关闭了"引用角标显示"，正文会显得更干净，但引用面板照常可见。

### 7.2 判断答案是否靠谱的三步

1. **先看引用来源**：来源是不是你最想参考的文档？时间对不对？
2. **点开原文对照**：角标点开原文分块，看答案是不是"原文说的"。
3. **交叉验证**：同一问题换一个知识库/换个措辞再问一次，看结论是否一致。

> 若回答里出现"**我没有找到相关信息**"或明显的猜测式措辞（如"可能是…""一般来说…"），说明检索没命中——此时请换更具体的问法，或联系管理员确认该知识是否在库。

## 8. 会话管理：历史、搜索、导出

### 8.1 会话列表

左侧**会话**页，列出你参与过的所有对话，按渠道分组：**Web（网页）/ IM（企业微信/飞书等）/ 嵌入（官网挂件）/ API**。

- 每条会话显示标题与最后一条消息摘要；
- 点击打开历史；
- 右键/更多菜单：**重命名**、**删除**（删除不可恢复）。

### 8.2 历史消息搜索

若系统开启了聊天历史索引：

1. 顶部**全局搜索框**（或设置 → 搜索历史）；
2. 输入关键词，跨会话检索消息内容；
3. 命中结果点击直接定位到具体轮次。

### 8.3 导出对话

会话操作栏 → **导出 Markdown**：

- 文件包含会话标题、时间、逐轮问答与引用来源；
- 格式为 `.md`，方便贴进周报、工单、或存档共享；
- 引用附原文链接（知识库分块 ID），便于复核。

> **注意**：导出的是你的会话内容，涉及敏感数据时请遵守公司数据外发规定。

## 9. 不打开网页也能用：IM 与小程序

管理员会把内脑接入企业 IM 或对外网站。作为使用者，你通常**不需要做任何配置**，直接找机器人/挂件用即可：

### 9.1 企业 IM 里的机器人

支持 **企业微信、飞书/Lark、钉钉、Slack、Telegram、微信、QQ 机器人、Mattermost、云之家** 10 个平台。

用法（以企业微信为例）：

1. 在企微的**工作台**里找到"企业内脑机器人"（或直接在群里 @机器人）；
2. 像发消息一样输入问题，机器人**流式打字**回复，附带引用；
3. 直接把文件/图片**发给机器人**，它解析后参与回答（若管理员开启了文件入库，还会自动沉淀到指定知识库）。

常用命令：

| 命令 | 作用 |
|------|------|
| `/help` | 列出所有可用命令 |
| `/reset` | 清空当前对话的上下文（相当于新开一轮） |
| `/new` | 开始一个新会话（不同上下文） |

> 不同平台命令略有差异，以 `/help` 实际输出为准。

### 9.2 微信小程序

1. 微信搜一搜"公司名+内脑"或扫管理员发的码；
2. 登录后可使用与网页相同的能力：选知识库、提问、附件；
3. 适合**手机移动场景**：出差在外查一份制度、随手问个参数。

### 9.3 官网 Widget（对外访客）

若公司官网或帮助中心有一个**右下角对话气泡**：

1. 点气泡打开对话窗口，**无需注册/登录企业内脑账号**；
2. 输入问题，机器人基于"客服 Agent"限定的知识库范围内回答；
3. 回答同样带引用来源。

> 访客模式下，联网搜索与文件上传默认关闭，以安全优先。

### 9.4 渠道切换不丢失上下文

- 网页里问的，换个手机在小程序里**看不到**——会话按"人+渠道"隔离；
- 但同一 IM 群里的对话上下文是延续的（除非 `/reset`）；
- 想跨渠道"接着上次聊"，建议用**网页全局搜索**找回原文再追问。

## 10. 浏览自动生成的 Wiki

管理员可以在知识库上开 **Wiki 索引**，系统会自动把文档**总结成相互链接的百科页面**：

- **总览页**：该库的核心内容概览；
- **实体页**：具体的人/事/物/概念（点击跳转关联页面）；
- **对比页 / 主题页**：跨文档的归纳；
- **摘要页**：单文档的浓缩总结。

对你来说：

| 场景 | 用法 |
|------|------|
| 想快速了解一个领域 | 直接看 Wiki 总览页，别翻原始文件 |
| 想知道某两个概念的区别 | 搜实体名 → 进入对应实体页 |
| 想找某个文档的浓缩 | 摘要页，一眼看完 |

> Wiki 页面上有**版本历史**——每次编辑都保留了快照，可对比与回滚（普通使用者只读浏览即可）。

## 11. 常见问题（使用者视角）

**Q1：我提的问题没找到答案怎么办？**
A：① 换个更具体的措辞（加年份/部门/产品线）；② 用 `@文档名` 点名文件；③ 切**智能推理**模式再试；④ 确认该知识确实已被管理员入库（可查**知识库**页文件列表）。都没有的话，找知识管理员补充知识。

**Q2：答案看起来不对 / 与我的认知冲突？**
A：先看引用来源——点开原文，核对原文是不是真的这么说。若引用对、答案却歪曲，说明模型理解偏差，请换措辞重问或反馈给管理员。若引用也不对，说明检索串了，换个知识库范围再试。

**Q3：我能看别人的会话吗？**
A：默认**不能**。你的会话只有你自己能看；管理员可以查看 IM 渠道产生的会话（只读），但看不到其他空间成员的个人会话。

**Q4：我能把对话里的内容外发吗？**
A：取决于公司保密规定。导出 Markdown 前请确认该内容是否允许外发；涉及机密内容的知识库通常由管理员单独授权。

**Q5：一个文件/图片问完还能再看吗？**
A：**不能**。临时附件随会话 24 小时过期清理，不进知识库。若要长期保留，让管理员入库。

**Q6：@提及一个文档没反应 / 找不到那个文档？**
A：① 文档还没入库或不在你有权访问的知识库范围；② 文档名拼错 / 太短；③ 该库正在重新解析，稍等再试。

**Q7：切了智能推理后特别慢？**
A：预期行为——它要跑多轮检索 + 工具调用 + 推理。若超过 2 分钟还没回，看进度条卡在哪一步（"正在联网"/"正在执行工具"等），必要时换个更聚焦的问法或切回快速问答。

**Q8：我建的会话别人也能看到？**
A：**你的会话私有**；但你在**共享组织**里使用的知识库产生的引用，其他人查同一知识库也能见到（引用的来源分块是公共的，你的对话记录还是私有）。

**Q9：能不能让机器人用我自定义的"角色口吻"？**
A：作为普通使用者不行（属于 Agent 配置），可联系管理员为你建一个预调好提示词的 **Agent**，然后你用那个 Agent 对话。

**Q10：我的账号被禁用了 / 进不去工作空间？**
A：找 IT 或空间管理员。常见原因：离职/转岗自动挂起、密码重置后需重新登录、所在组织被移除。

**Q11：同一问题不同人问，答案会一样吗？**
A：不一定。原因有三：① 各自能访问的知识库范围不同；② 各自选择的知识库集合不同；③ 大模型本身随机性（不同次提问会有措辞差异，但引用来源一致时核心结论应该一致）。

**Q12：能语音提问吗？**
A：当前版本 Web 端未内置语音输入（若管理员配置了 ASR 语音转写，可用于解析音频文件附件）。建议先用文字提问。
