# 4. 智能问答与智能体

本章讲"对话框"本身：一次问答能看到什么、能做什么；两种模式怎么切换；如何创建与配置自定义智能体；以及 FAQ 问答对的管理。

---

## 4.1 一轮问答里你能看到什么

| 界面元素 | 说明 |
|---------|------|
| **流水线进度条** | 回答生成前展示当前阶段：附件解析 → 图片理解 → 检索文档 → 联网 → 工具调用 → 思考 → 生成回答 |
| **思考过程** | 智能推理模式下，模型推理内容内联展示，可折叠 |
| **引用角标** | 回答正文中的来源标记，点击定位原文分块 |
| **引用面板** | 侧栏列出本轮所有检索来源（区分知识库 / 网络来源，含 Wiki 工具返回结果） |
| **追问建议** | 回答结束后给出的下一步问题，点一下即可继续问 |

> **引用开不开，与引用面板无关**：Agent 配置里的"显示引用"只控制**正文角标**。关掉后正文变干净，但检索来源照常进引用面板——"不显示角标"不等于"没有出处"。

**导出对话**：会话操作栏 → 导出 Markdown（含标题、时间、逐轮问答），适合贴进工单或周报。

### 提问前可以做的事（上下文控制）

| 操作 | 效果 |
|------|------|
| 选择知识库（可多选） | 限定检索范围 |
| `@提及` 具体文档 / 标签 | 本轮优先聚焦被提及的内容 |
| `@MCP` 服务 / `@Skill` 技能 | 强制本轮使用对应工具/技能 |
| 上传图片 / 附件 | 临时文档参与本次问答（见 §4.4） |
| 开/关联网搜索 | 允许 Agent 搜索实时信息 |

## 4.2 两种问答模式（顶部切换）

| 模式 | 适合 | 代价 |
|------|------|------|
| **快速问答**（quick-answer） | 事实性提问，答案就在文档里 | 一轮检索，快、省 Token |
| **智能推理**（smart-reasoning） | 需要多步骤、跨文档、要联网或调工具 | 多轮模型调用，慢一些、贵一些 |

### 智能推理（ReAct Agent）是什么

普通问答是"检索一次、回答一次"；智能推理是**边想边做**：Agent 自己决定检索几轮、要不要联网、要不要调外部工具，逐步积累依据，直到攒够证据再给出最终答案，并在界面展示完整的思考与工具调用时间线。

典型例子：*"对比这三份合同的付款条款，并查一下行业惯例"*——Agent 会分别检索三份相关文档片段、必要时联网搜索、必要时用数据分析工具算数，最后给出带依据的对比结论。

### 内置 Agent（开箱即用）

| Agent | 用途 |
|-------|------|
| 快速问答（builtin-quick-answer） | 经典 RAG：单次检索 + 回答 |
| 智能推理（builtin-smart-reasoning） | ReAct 多步推理 + 全量工具 |
| 数据分析（builtin-data-analyst） | 对上传的 CSV/Excel 执行 SQL 统计分析 |
| Wiki 研究员 / Wiki 修复员 | 基于 Wiki 的知识研究与页面维护 |

## 4.3 自定义智能体（Agent 管理）

入口：「智能体」页。除内置 Agent 外，可以建立自己的 Agent，配置好之后既能在网页对话中使用，也能绑到 IM 渠道或网站嵌入上对外服务。

### 配置项一览

| 配置项 | 说明 |
|--------|------|
| **模式** | 快速问答 / 智能推理（选智能推理才有工具能力） |
| **类型预设** | 智能推理下：RAG 问答 / Wiki 问答 / 混合 / 数据分析 / 完全自定义 |
| **对话模型** | 该 Agent 用的 LLM（可覆盖默认） |
| **知识库范围** | 勾选它能检索的知识库（限定知识边界的关键） |
| **联网搜索** | 开关 + 搜索引擎（见 §4.6） |
| **MCP 工具** | 从已接入的 MCP 服务勾选该 Agent 可用工具（all / 指定 / 不用） |
| **技能（Skills）** | 挂载自定义技能（脚本化流程，沙箱执行） |
| **提示词** | 自定义 System Prompt，定义角色、语气、回答规范（支持占位符：知识库列表、联网状态、当前时间、语言） |
| **引用显示** | 正文角标开关（不影响引用面板） |
| **思考模式** | 按模型配置是否开启思维链 |
| **附件策略** | 可传文件类型、是否理解图片、附件走哪个解析引擎 |
| **允许查看者运行** | 默认开；关掉后需编辑者角色以上才能用该 Agent |

### Agent 可用的内置工具（智能推理模式）

| 类别 | 工具（示例） | 用途 |
|------|-------------|------|
| 知识检索 | `knowledge_search`（混合检索）、`grep_chunks`（关键词精搜） | 找文档片段 |
| Wiki 导航 | `wiki_search` / `wiki_read_page` / `wiki_write_page` 等 10 个 | 把 Wiki 当长期记忆读写 |
| 网页 | `web_search` / `web_fetch` | 联网搜索 + 抓取网页并分析 |
| 数据分析 | `data_schema` / `data_analysis` | 对 CSV/Excel 跑 SQL（DuckDB，会话结束自动清理） |
| 技能 | `read_skill` / `execute_skill_script` | 读取技能说明、在沙箱执行技能脚本 |
| MCP 外部 | `mcp_{服务}_{工具}` | 调外部系统（工单、数据库、内部 API 等） |

> **安全提示**：对有副作用的 MCP 工具（写操作、外发消息）建议开启**人工审批**——Agent 调用前会先向当前用户确认；OAuth 类外部服务支持**会话内授权**（用户点一下完成授权后继续）。

## 4.4 临时附件（会话级文件问答）

对话里可以直接丢文件进去问，不必先建知识库：

- 上传的图片/文档只属于**当前会话**，异步解析后参与问答；
- 不进向量索引、不出现在知识库列表，**会话结束即清理**（默认保留 24 小时）；
- 扫描件/图片走视觉模型 OCR（并发与页数上限可调）；
- 需要长期检索的资料，请正式入库。

> 用法示例：丢一份 PDF 合同进去问"付款条款有哪些？"——不污染正式知识库，一次性分析场景很合适。

## 4.5 FAQ 问答对管理

有些问题的答案是固定的（退货政策、报销流程、常见报错）。这类内容直接维护成问答对，比文档检索更稳定可靠：

### 使用建议

1. **批量导入**：先用 Excel / CSV 导入历史工单里的常见问题（支持追加/替换两种模式，异步执行、可查进度）;
2. **界面补充相似问**：同一意思问法越多，命中率越高；
3. **补反例问**：容易误命中的相近问题标为反例，命中即过滤，防止答非所问；
4. FAQ 库可以和文档库**一起被同一个 Agent 检索**，形成"先查标准答案、查不到再翻文档"的效果。

### 条目结构

| 字段 | 说明 |
|------|------|
| 标准问 | 必填，该条目的主问题 |
| 相似问 | 可选列表，同一问题的其他问法 |
| 反例问 | 可选列表，命中即排除的问题 |
| 答案 | 至少一个；可多答案 |
| 答案策略 | `all`（返回全部答案）/ `random`（随机一个） |
| 标签 / 启用开关 | 分类管理、临时停用 |
| 推荐问题 | 标记后可作为会话开场推荐问题 |

### 管理功能

- 列表筛选（标签 / 关键词：按标准问/相似问/答案）、批量更新（启用/推荐/策略/标签）、批量删除;
- 检索预览：直接试搜，看命中哪条、命中哪个问法、得分多少;
- 导出：CSV / JSON，便于迁移与备份;
- 导入进度与结果追踪：逐条成功/失败原因。

> 系统会自动做重复检查（相似问 vs 标准问、反例 vs 标准问、跨条目冲突），避免同义条目互相打架。

## 4.6 联网搜索

Agent 开启联网搜索后，可用两类工具：

- **联网搜索（web_search）**：按问题实时搜索，多引擎可选：DuckDuckGo（免费无需 Key）、Google、Bing、Tavily、百度、Ollama、SearXNG（自托管）、智谱等;
- **网页抓取（web_fetch）**：抓取指定 URL 正文，交由大模型分析提炼。

配置位置：空间设置（搜索引擎与 Key）或 Agent 级（是否允许联网）。自托管 SearXNG 可用 `docker compose --profile searxng up -d` 一键启动。

> 所有外部抓取都有 SSRF 防护（禁止访问内网地址），搜索结果的来源会标注在引用面板中（与知识库来源区分显示）。

## 4.7 对话体验增强

| 能力 | 说明 |
|------|------|
| **开场推荐问题** | 基于知识库内容自动生成"你可能想问"；也可用 FAQ 推荐位手动指定 |
| **答后追问** | 每轮回答后给出下一步建议问题，引导深入 |
| **多轮上下文** | 自动携带历史对话；长对话支持上下文压缩（滑动窗口 / LLM 摘要）防超窗口 |
| **会话管理** | 侧边栏按来源（Web / IM / 嵌入 / API）分组筛选；标题可内联重命名；历史消息可跨会话搜索（需开启聊天历史索引） |
| **Markdown 统一渲染** | 回答支持公式、表格、代码块、Mermaid 图表 |
| **思考模式** | 支持思维链的模型可开启"先思考再回答"，适合推理类问题 |

## 4.8 推荐组合（按场景）

| 场景 | 推荐配置 |
|------|---------|
| 员工日常查制度/查参数 | 快速问答 + 文档库（开 Rerank）+ FAQ 库（固定答案） |
| 售前/客服对外服务 | 自定义 Agent（限定知识库范围 + 联网开 + 欢迎语），挂到嵌入渠道或 IM |
| 数据团队查报表 | 数据分析 Agent：丢 Excel/CSV 直接问 SQL 问题 |
| 新人培训 | Wiki 模式文档库 + Wiki 研究员 Agent |
| 法务/合规审查 | 智能推理 + 联网 + 自定义提示词（输出模板化结论） |
