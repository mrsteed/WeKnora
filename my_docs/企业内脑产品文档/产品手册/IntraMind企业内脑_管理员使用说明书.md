## 1. 概述

### 1.1. 系统概述

针对企业内部各类文档知识提供基于大语言模型的智能问答、智能推理与自动 Wiki 服务。本说明书面向**管理员**，覆盖成员与角色管理、模型配置、知识库建设与维护、智能体配置、渠道发布（IM/官网/API）、跨空间共享、系统级设置、任务运维与审计等全部管理操作。

普通使用者（查看者）的日常提问操作见《IntraMind企业内脑_使用说明书》，本说明书不再重复。

### 1.2. 系统用户

| 角色 | 级别 | 管理范围 | 本说明书适用章节 |
|------|------|---------|----------------|
| **查看者 Viewer** | 1 | 仅提问、浏览 | 不适用（见使用者说明书） |
| **编辑者 Contributor** | 2 | 自己创建的知识库、Agent、FAQ | 2.3–2.6（限自己创建的资源） |
| **管理员 Admin** | 3 | 空间内全部资源与公共配置 | 2.1–2.8 全部 |
| **所有者 Owner** | 4 | Admin 全部权限 + 删除/转让空间 | 2.1–2.8 全部 |
| **系统管理员** | 平台级 | 整个部署：全局设置、任务队列、平台级密钥、系统审计 | 2.9（+ 跨空间能力，见 2.10） |

**角色阶梯**：查看者 < 编辑者 < 管理员 < 所有者，高角色继承低角色全部权限。系统管理员属于**平台级**身份，与空间角色互不叠加（系统管理员进入某个空间时，其在该空间内仍有独立的成员角色）。

**资源归属规则**：知识库、Agent、FAQ 条目、Wiki 页面均记录创建者。编辑者对**自己创建**的资源拥有等同所有者的权限，对**他人创建**的资源等同查看者；"空间共有"（无创建者）的资源仅管理员及以上可变更。

## 2. 使用说明

### 2.1. 成员管理

**功能描述**

管理工作空间的成员：邀请加入、分配角色、挂起或移除。

#### 2.1.1. 邀请成员

**功能描述**

通过邮箱邀请新用户加入当前工作空间，并指定其角色。

**操作方法**

1）进入【空间设置】→【成员】；

2）点击【邀请成员】，输入对方邮箱，选择角色（编辑者/管理员/查看者），点击【发送邀请】；

3）被邀请人收到邀请后接受，状态由"待接受"变为"已激活"，即获得对应权限；

4）邀请长期未接受可在成员列表中撤销。

#### 2.1.2. 角色管理

**功能描述**

调整已有成员的角色权限。

**操作方法**

1）进入【空间设置】→【成员】；

2）选择目标成员，点击【修改角色】；

3）选择新角色并确认，权限立即变更（已有会话不受影响，权限判断在下次请求时生效）；

4）系统保护：删除空间前必须保证至少保留一位所有者；不可撤销自己。

| 角色 | 赋予它的场景 |
|------|-------------|
| 编辑者 | 知识维护员：建自己的库、传文档、管 FAQ |
| 管理员 | 空间运维：管成员、配模型与公共配置、变更任意资源 |
| 所有者 | 空间负责人：全部权限，每空间至少一位、可多位 |

#### 2.1.3. 注册模式

**功能描述**

控制新账号的进入方式（管理员及以上，位于空间设置 → 系统）。

**操作方法**

1）进入【空间设置】→【系统】→【注册模式】；

2）选择"自助注册"（默认，任何人可注册并自动获得个人空间）或"邀请制"（团队部署推荐，新用户必须经邀请才能加入）；

3）保存后立即生效。

**提示**：生产环境建议启用"邀请制"，杜绝陌生人注册占用资源。

### 2.2. 模型管理

**功能描述**

管理空间可用的五类模型：对话（LLM）、向量（Embedding）、重排（Rerank）、视觉（VLM）、语音（ASR）。模型先全局添加，再按知识库/Agent 选用。

#### 2.2.1. 添加模型

**功能描述**

接入一个模型服务（本地 Ollama 或 26 家远程厂商，支持任意 OpenAI 兼容接口）。

**操作方法**

1）进入【设置】→【模型】，点击【添加模型】；

2）选择模型类型（对话/向量/重排/视觉/语音）；

3）选择厂商（Ollama 本地、OpenAI、DeepSeek、通义、智谱、混元、豆包、Kimi 等 26 家，或"通用兼容"）；

4）填写 Base URL、API Key、模型名称（本地 Ollama 填 `http://host.docker.internal:11434`，**不是** localhost）；

5）点击【测试】验证连通，成功后点击【保存】。

**提示**：向量模型决定知识库索引的含义，**建库后不可更换**（更换需全量重建索引），请在建库前规划好。

#### 2.2.2. 模型测试与调试

**功能描述**

不建库验证模型可用性，并预览问答效果。

**操作方法**

1）在模型列表中对目标模型点击【调试】；

2）输入测试问题，观察回答质量、延迟；

3）向量模型可查看维度、试嵌入一段文本；

4）调试通过后，在知识库或 Agent 中选择该模型。

#### 2.2.3. 内置模型

**功能描述**

随部署预置的模型（YAML 声明式配置），供全空间开箱选用，免逐个接入。

**操作方法**

1）【设置】→【模型】中"内置模型"分组的模型可直接选用；

2）编辑 `config/builtin_models.yaml` 可增删预置（修改后重启服务生效）。

**提示**：本地与远程模型可混用（如本地小模型做向量化，远程大模型做回答），按成本与合规灵活组合。

### 2.3. 知识库管理

#### 2.3.1. 创建知识库

**功能描述**

创建一个知识容器，配置其类型、模型与基础参数。

**操作方法**

1）进入【知识库】，点击【新建知识库】；

2）填写名称、描述，选择类型：

| 类型 | 用途 |
|------|------|
| 文档（默认） | 装 PDF/Word/网页/音视频等文件资料 |
| FAQ | 装"标准问 + 答案"的固定问答对 |

3）在初始化向导中配置模型：对话模型（必填）、向量模型（**必填，建库后不可换**）、重排（建议开启）、图片理解/语音转写（按需）、Wiki 与图谱索引开关（按需，见 2.6）；

4）保存。建库前系统校验空间剩余存储配额（默认每空间 10GB）。

**提示**：库绑定的向量存储创建后不可修改，创建前确认所选检索引擎（默认 PostgreSQL 即可，绝大多数部署无需更换）。

#### 2.3.2. 分块配置

**功能描述**

配置文档切分为检索单元的规则（库编辑 →【分块】页签）。多数场景用默认值（512 字 / 重叠 80 字 / 自适应策略）。

**操作方法**

1）编辑知识库 →【分块】页签；

2）按需调整：

| 参数 | 默认 | 调整依据 |
|------|------|---------|
| 分块大小 | 512 字 | 回答缺上下文调大；命中不相关调小 |
| 重叠 | 80 字 | 条目式资料（FAQ/参数表）设 0；长篇叙述设 150–200 |
| 策略 | 自适应 | 可按标题/启发式/递归固定策略 |
| 父子分块 | 关 | 长文档开启：子块负责检索命中，父块（约 4096 字）提供回答上下文 |
| 分隔符 | 段落→换行→句号 | 条目式资料建议用换行 |

3）使用【分块预览】对一篇文档试切，确认效果后保存（预览不入库）；

4）**修改分块配置后，已有文档需重新解析才生效**（见 2.3.8）。

#### 2.3.3. 索引策略

**功能描述**

配置该库参与问答的四路索引与富化开关（库编辑 →【索引策略】页签）。

**操作方法**

1）编辑知识库 →【索引策略】；

2）按需开关：

| 开关 | 默认 | 说明 |
|------|------|------|
| 向量检索 | 开 | 语义相似度检索（依赖向量模型） |
| 关键词检索 | 开 | BM25 精确命中，与向量互补 |
| Wiki 生成 | 关 | 生成自动 Wiki（见 2.6.1） |
| 知识图谱 | 关 | 抽取实体与关系（需部署 Neo4j，见 2.6.3） |

3）富化选项：开启【问题预生成】（为每个分块预生成口语化问题，提升召回）、【图片理解】（需先配置视觉模型）、【语音转写】（需先配置 ASR 模型）。

#### 2.3.4. 上传文档

**功能描述**

向知识库添加本地文件，异步解析并建立索引。

**操作方法**

1）进入目标知识库，将文件拖入上传区（或点击选择）；

2）支持整目录拖入，自动按原目录结构建立文件夹树；

3）上传确认对话框中可顺手【打标签】、调整本批解析选项（如指定解析引擎）；

4）保存后文档进入解析队列，列表页实时显示状态：等待中 → 处理中 → 收尾富化 → 已完成（失败/可取消）。

**支持格式**：

| 类别 | 格式 |
|------|------|
| 文档 | PDF、Word、PPT、Excel、EPUB |
| 文本 | TXT、Markdown、CSV、JSON |
| 网页 | 本地 HTML / MHTML 归档 |
| 图片 | JPG、PNG、GIF、BMP、TIFF、WebP（需视觉模型） |
| 音频 | MP3、WAV、M4A、FLAC、OGG（需 ASR 模型） |

#### 2.3.5. 网页导入

**功能描述**

粘贴网页地址，系统抓取正文转 Markdown 入库（带 SSRF 防护，禁止内网地址）。

**操作方法**

1）知识库文档列表页，点击【新建】→【从网址导入】；

2）粘贴 URL，确认抓取预览；

3）保存，进入异步解析队列。

#### 2.3.6. 手动录入

**功能描述**

直接撰写 Markdown 条目入库，适合零散知识沉淀（草稿可先存后发布）。

**操作方法**

1）知识库文档列表页，点击【新建】→【手动录入】；

2）在编辑器中编写内容（支持 Markdown），填写标题与标签；

3）保存并发布，进入解析队列。

#### 2.3.7. 文件夹与标签

**功能描述**

用文件夹树与多标签整理库内文档。

**操作方法**

1）文档列表左侧【文件夹树】：新建/重命名文件夹，将文档拖入归档；

2）单篇文档在详情页【标签】区增删标签（一篇可多标签）；

3）多篇整理：勾选多篇 → 底部操作栏【标签】批量应用、【移动】批量归档；

4）文档详情页可维护【自定义元数据】（最多 20 个字段，如部门/密级/版本号，值限字符串/数字/布尔），用于内部管理。

#### 2.3.8. 重新解析

**功能描述**

文档内容更新或解析配置变更后，重新走解析流水线（无需重传文件）。

**操作方法**

1）单篇：文档详情页点击【重新解析】，可顺带调整本批解析选项（换引擎、改开关）；

2）批量：文档列表勾选多篇 →【批量重新解析】，可携带批次级配置；

3）任务队列中排队执行，完成后状态回到已完成，索引自动更新。

**提示**：解析一直"处理中"时，打开解析追踪时间线定位卡住阶段；任务队列面板可重试失败任务（解析追踪入口见 2.10.2）。

#### 2.3.9. 分块编辑

**功能描述**

直接修改检索分块（解析错字、切错、OCR 误识别时不必重传文档），保存自动重建索引。

**操作方法**

1）打开文档 →【分块】列表 → 点击目标分块；

2）编辑文本，点击【保存】，系统自动重新向量化该分块，检索即时生效；

3）【版本历史】：查看任意历史版本、逐行对比（diff）、一键【回滚】到指定版本；

4）分块上的【生成问题】可增/删/改/重新生成（预生成问题质量直接关系口语化提问的召回率）。

**提示**：对高频被问的核心文档人工校对分块与生成问题，是"低成本提升答案质量"最有效的手段。

#### 2.3.10. 数据源配置

**功能描述**

绑定外部内容源（飞书/Lark 知识库、Notion、语雀、RSS），按计划自动同步新增与修改，外部删除同步下架。数据源挂在知识库上。

**操作方法**

1）编辑目标知识库 →【数据源】页签 →【新建连接】；

2）选择数据源类型，填写凭据并在线授权（凭据 AES-256-GCM 加密落库，接口不回显）；

3）选择同步范围（外部空间/目录/文档）与同步模式：

| 配置 | 说明 |
|------|------|
| 同步周期 | Cron 表达式（如每日凌晨）手动触发亦可 |
| 同步模式 | 增量（推荐，按修改时间拉取）/ 全量 |
| 删除同步 | 外部删除时库内同步删除（可选） |
| 冲突策略 | 同名文档更新冲突时以外部为准/保留本地编辑 |

4）保存后按周期自动执行；【同步日志】记录每次执行的新增/更新/删除/跳过/失败条数，失败样本给出可读原因（凭据过期时重新授权即可）。

#### 2.3.11. 整库复制与删除

**功能描述**

复制知识库（含全部知识、分块、配置）或级联删除。

**操作方法**

1）【整库复制】：知识库列表 →【复制】，输入副本名称；异步复制，列表可查进度；适合"按部门拆库但内容同源"；

2）【跨库迁移文档】：文档列表勾选多篇 →【移动到知识库】（移动不复制，原库删除）；

3）【置顶】：知识库列表 →【置顶】，将常用库固定在顶部；

4）【删除】：知识库列表 →【删除】，二次确认后**级联清空**其下全部知识、分块、索引、Wiki 页面、标签与源文件，**不可恢复**。

**提示**：删除前请用"整库复制"做备份或先导出。

### 2.4. FAQ 管理

#### 2.4.1. 新增 FAQ 条目

**功能描述**

维护"标准问 + 答案"问答对。适合制度、流程、常见报错等固定答案内容，命中即直出，比文档检索更稳定。

**操作方法**

1）进入 FAQ 类型知识库 →【新增条目】；

2）填写：标准问（必填）、相似问（多种问法，越多命中越高）、反例问（易误命中的相近问题，命中即排除）、答案（至少一个）、答案策略（返回全部/随机一个）；

3）打标签、设置启用开关，保存。

**提示**：FAQ 库可与文档库挂给同一个 Agent 检索，形成"先查标准答案、查不到再翻文档"的效果。

#### 2.4.2. 批量导入

**功能描述**

用 Excel / CSV 批量导入问答对（适合导入历史工单沉淀），异步执行、可查进度。

**操作方法**

1）FAQ 知识库列表页 →【批量导入】；

2）选择文件，选择模式：追加（保留存量）或替换（清空后导入）；

3）提交后查看导入进度与逐条成功/失败原因；

4）系统自动做重复检查（相似问与标准问、反例与标准问、跨条目冲突）。

#### 2.4.3. 检索预览与维护

**功能描述**

验证 FAQ 命中情况，批量维护条目。

**操作方法**

1）【检索预览】：输入一句话试搜，查看命中哪条、命中哪个问法、得分多少；

2）列表按标签/关键词筛选（匹配标准问/相似问/答案）；

3）勾选多条 → 批量启用/停用、批量设推荐问题、批量改标签/策略、批量删除；

4）【导出】为 CSV / JSON，便于迁移备份；

5）标记【推荐问题】的条目可作为会话开场推荐。

### 2.5. 智能体管理

**功能描述**

创建与配置 Agent（把模型 + 知识范围 + 工具 + 提示词打包成可复用的问答角色），供网页对话、IM 渠道、官网嵌入使用。

#### 2.5.1. 创建自定义智能体

**功能描述**

新建一个 Agent 并配置其能力边界。

**操作方法**

1）进入【智能体】页 →【新建智能体】；

2）配置核心项：

| 配置项 | 说明 |
|--------|------|
| 名称/描述 | 界面展示与识别用 |
| 模式 | 快速问答（单轮检索）/ 智能推理（多轮工具调用，**仅推理模式可调工具**） |
| 对话模型 | 该 Agent 专用 LLM（可覆盖空间默认） |
| 知识库范围 | 勾选可用库——**限定知识边界的关键** |
| 联网搜索 | 开关（配合 2.8.3 配置的搜索引擎） |
| MCP 工具 | 从已接入服务勾选可用工具 / 全部 / 不用 |
| 技能 | 挂载脚本化技能（沙箱执行，如 PDF/Excel/PPT 处理） |
| 附件策略 | 可传文件类型、是否理解图片 |
| 允许查看者运行 | 默认开；关闭后需编辑者及以上使用 |

3）保存。该 Agent 即可在网页【智能体】页使用，也可在渠道（2.7）中绑定对外服务。

**内置工具速查**（智能推理模式自动可用）：知识检索、关键词精搜、Wiki 读写（10 个工具）、联网搜索与抓取、数据分析（对 CSV/Excel 执行 SQL，基于 DuckDB，会话结束自动清理）、技能读写与沙箱执行、MCP 外部工具。

#### 2.5.2. 配置提示词

**功能描述**

定制 Agent 的角色、语气与回答规范（System Prompt）。

**操作方法**

1）编辑 Agent →【提示词】；

2）编写角色设定与回答要求，支持占位符：知识库列表、联网状态、当前时间、语言；

3）用【调试对话】试聊验证效果后保存。

**提示**：对对外客服场景，提示词中写清"回答范围、拒答口径、语气"，配合小范围知识库，行为最可控。

#### 2.5.3. 接入 MCP 外部工具

**功能描述**

让 Agent 作为 MCP 客户端挂载外部工具服务（工单系统、数据库、内部 API 等）。

**操作方法**

1）【设置】→【MCP 服务】→【新建服务】；

2）填写服务名、接入方式（SSE / HTTP / stdio）、地址与凭据；

3）选择鉴权方式：API Key / OAuth2（支持会话内授权）；

4）【连通测试】通过后保存；

5）回到 Agent 配置 →【MCP 工具】勾选该 Agent 可使用的具体工具；

6）对**有副作用的工具**（写操作、外发消息）建议开启【人工审批】：Agent 调用前先向用户确认。

**提示**：OAuth 类服务授权过期后用户点一下即可在会话内重新授权；工具调用失败的排查见 3. 常见问题 Q8。

### 2.6. Wiki 与知识图谱

#### 2.6.1. 开启自动 Wiki

**功能描述**

让系统从文档自动抽取条目、生成相互链接的百科页面与图谱（异步、增量更新）。

**操作方法**

1）编辑目标知识库 →【索引策略】→ 打开【Wiki】；

2）选择生成粒度：

| 粒度 | 抽取范围 |
|------|---------|
| 聚焦 | 仅 3–7 个主要主题（试水推荐） |
| 标准（默认） | 主要主题 + 实质性讨论的实体概念 |
| 详尽 | 穷举所有命名事物与公认概念（小范围高价值库） |

3）配置生成模型；

4）保存后随文档入库异步生成（已入库文档自动纳入，无需重传）；

5）完成后进入知识库【Wiki】页签浏览：目录树（三级分类）、实体/概念/摘要/索引/对比页，页面互链且带原文出处。

**提示**：生成调用大模型，成本与文档量成正比。新增文档只更新受影响页面（增量机制），不会整库重建。

#### 2.6.2. 编辑 Wiki 页面

**功能描述**

对自动生成的页面做人工修订，全部改动留版本、可回滚。

**操作方法**

1）Wiki 页面点击【编辑】，浏览器内修改 Markdown 正文；

2）保存即生成版本快照；

3）【版本历史】：查看任意两版本的行级 diff、改动时间与操作人；

4）【回滚】到任意历史版本（回滚本身也生成新版本，可再回退）。

**提示**：Agent 对 Wiki 的写入同样走版本机制，"Agent 改坏的页面"也能找回原版。

#### 2.6.3. 开启知识图谱

**功能描述**

从文档抽取实体与关系存图，问答时按关系多路召回（GraphRAG）。适合关系密集资料（组织架构、供应链、合同网络）。

**操作方法**

1）平台前提：已部署 Neo4j（`docker compose --profile neo4j up -d`，`NEO4J_ENABLE=true`）；

2）编辑知识库 →【索引策略】→ 打开【图谱】；

3）配置抽取参数：

| 参数 | 说明 |
|------|------|
| 关系类型标签 | 如"属于/负责/依赖/付款给" |
| few-shot 示例 | 样例文本 + 期望抽取结果（可自动生成） |
| 领域指令 | 追加业务术语说明到抽取提示词 |

4）用【图谱试抽取】选一段文本预览抽取效果，满意后正式启用；

5）文档入库后异步抽取（独立队列，失败自动重试最多 3 次）；

6）知识库【图谱】页签查看可视化实体/关系图，点节点查看关联文档。

**提示**：抽取每分块额外一次模型调用，成本高于 Wiki；对量大但价值不均的库谨慎全量开启。

### 2.7. 渠道管理

#### 2.7.1. 配置 IM 机器人

**功能描述**

把 Agent 发布到企业 IM（企业微信、飞书/Lark、钉钉、Slack、Telegram、微信、QQ 机器人、Mattermost、云之家，共 10 平台）。

**操作方法**

1）在 IM 平台后台创建应用/机器人，取得凭据（AppKey/Secret、Token 等，表单有字段提示）；

2）【设置】→【IM 集成】→【新建渠道】；

3）选择平台，填写凭据；

4）**绑定一个 Agent**（决定机器人用哪些库、能否联网、挂哪些工具）；

5）可选：绑定【文件入库知识库】——用户发给机器人的文件自动解析入库，实现"边聊边沉淀"；

6）选择接入模式：

| 模式 | 说明 |
|------|------|
| websocket / 长连接 / 长轮询（多数默认） | 系统主动连平台网关，**无需公网地址**，内网可用 |
| webhook | 回调地址填到平台事件订阅，需公网可达 |

7）配置输出模式（流式/整段）与会话模式（按人+群 / 按线程）；

8）点击【启用】，在 IM 中 @机器人 验证。

**提示**：机器人失联时优先检查凭据是否过期、平台回调是否变更（见 3. 常见问题 Q6）。

#### 2.7.2. 配置网站嵌入

**功能描述**

生成官网 Widget：访客免登录对话，由绑定 Agent 决定可答范围。

**操作方法**

1）【设置】→【网页嵌入】→【新建渠道】；

2）绑定 Agent；

3）配置【域名白名单】（必填）：完整域名 / 子域通配 `*.example.com`；`*` 仅开发模式允许，**生产环境拒绝**；

4）外观配置：欢迎语、标题、主题色、挂件位置（四角）、推荐问题开关；

5）安全额度：单 IP 每分钟上限（默认 30）、渠道每日总量（默认 10000）；访客侧联网搜索与文件上传默认关；

6）保存后复制生成的 `<script>` 代码片段，贴入目标网页上线；

7）用【预览会话】验证效果。

**提示**：渠道令牌（`em_` 前缀）可随时**轮换**，旧令牌与已签发会话立即失效——发生泄露时第一时间轮换。

#### 2.7.3. 管理 API Key

**功能描述**

为程序化集成签发凭证，支持细粒度能力与知识库范围限定（最小授权原则）。

**操作方法**

1）【空间设置】→【API Key】→【新建】；

2）输入名称，勾选能力（按最够用原则）：

| 能力 | 覆盖操作 |
|------|---------|
| retrieve | 检索、读库/文档/分块 |
| chat | 会话与问答（含 Agent 对话） |
| ingest | 上传入库 |
| manage_kbs | 知识库增删改、复制 |
| manage_models | 模型管理 |
| message_history | 历史消息搜索 |

3）可用【知识库范围】把 Key 锁定在指定库，范围外请求直接拒绝；

4）保存后把 Key 交付集成方，请求头携带 `X-API-Key`；

5）日常维护：查看 last_used 使用情况、【撤销】立即失效、可平滑轮换；

6）内置【API 集成调试台】可在线填参数试跑端点，便于交付前联调。

**提示**：服务端集成建议用 API Key 而非用户 JWT（长期有效、权限可控）。

### 2.8. 空间设置

#### 2.8.1. 注册与存储引擎

**功能描述**

配置空间的检索引擎（向量存储）与容量配额。

**操作方法**

1）【空间设置】→【向量存储】：查看当前引擎（默认 PostgreSQL/ParadeDB，向量 + BM25 一体，多数部署无需更换）；

2）复用公司现有栈时可注册 Elasticsearch / OpenSearch / Qdrant / Milvus / Weaviate 等实例，**按知识库绑定**不同实例（新库生效；已建库的绑定不可更改）；

3）【空间设置】→【系统】→【存储配额】：查看用量，所有者可调整配额上限。

#### 2.8.2. 对象存储

**功能描述**

配置文档源文件的存储后端：本地 / MinIO / 腾讯云 COS / 火山引擎 TOS / AWS S3 / 阿里云 OSS / 金山云 KS3 / 华为云 OBS。

**操作方法**

1）【设置】→【存储】→【新建存储实例】；

2）选择类型，填写 bucket、endpoint、密钥（S3 支持 IAM Role / IRSA 免密钥凭据链）；

3）测试连通后保存，可设为空间默认实例，或按知识库单独绑定。

#### 2.8.3. 搜索引擎

**功能描述**

配置 Agent 联网搜索使用的引擎与凭据。

**操作方法**

1）【设置】→【搜索引擎】；

2）选择引擎：DuckDuckGo（免费无需 Key）、Google、Bing、Tavily、百度、SearXNG（自托管）等；

3）填写 API Key（需要时），点击【测试】；

4）保存。Agent 开启联网搜索后按此配置生效。

**提示**：无商业 Key 时可用 `docker compose --profile searxng up -d` 一键部署自托管 SearXNG。

#### 2.8.4. 跨空间共享

**功能描述**

通过"组织"把知识库/Agent 以只读或可写权限共享给另一个空间（如产品部库共享给客服部）。

**操作方法**

1）【设置】→【组织】→【新建组织】，生成邀请码；

2）双方空间以管理员/编辑者/只读身份加入组织；

3）在目标知识库上【共享到组织】，选择共享权限（只读/可写）；

4）对方空间成员即在知识库列表看到并使用该库；

5）【取消共享】立即生效，已复制的副本不受影响。

**要点**：共享不改变资源归属（库仍属原空间）；"可写"共享受源空间归属规则约束（源库仅管理员可写时，外部一律只读）。

### 2.9. 系统管理（平台级）

> 本章节功能仅**系统管理员**可见（页面侧栏底部【系统控制台】）。首次部署的系统管理员通过环境变量 `WEKNORA_BOOTSTRAP_SYSTEM_ADMIN_EMAIL` 指定并重启服务生效。系统管理员身份不叠加空间角色。

#### 2.9.1. 系统设置

**功能描述**

全局运行时开关，**改完立即生效，无需重启**（数据库值优先于环境变量）。

**操作方法**

1）进入【系统控制台】→【系统设置】；

2）按需调整：

| 设置项 | 说明 |
|--------|------|
| 注册模式 | 自助注册 / 邀请制（全局兜底） |
| 空间策略 | 是否允许自助建空间、每用户最多拥有数（默认 10）、默认配额（默认 10GB，仅对新空间生效） |
| 任务队列并发 | 各 Worker 池并发上限（core/后处理/富化/维护/Wiki 独立池） |
| 模型并发上限 | 单模型最大并发（默认 32） |
| SSRF 白名单 | 允许抓取的内网地址例外清单（默认空 = 全禁） |

3）保存即生效；【重置】某项可删除数据库覆盖值，回落到环境变量。

#### 2.9.2. 任务队列

**功能描述**

监控全部异步任务（解析、向量化、Wiki、图谱、数据源同步）的实时积压与失败。

**操作方法**

1）【系统控制台】→【任务队列】，查看各队列积压与重试情况；

2）失败任务：查看失败原因 →【重试】；重试耗尽进入死信队列，可【重放】；

3）批量操作：【归档】/【删除】/【清空归档】；

4）高峰期或大批量上传后重点关注 core 池积压。

**提示**：所有异步任务失败自动重试（图谱最多 3 次），不丢任务；任务卡住时先查这里再看日志。

#### 2.9.3. 管理员管理

**功能描述**

提升/撤销系统管理员，管理用户密码与平台级密钥。

**操作方法**

1）【提升系统管理员】：选择用户 → 确认；被提升者立即可见系统控制台；

2）【撤销】：不可撤销自己、不可撤销最后一位系统管理员；

3）【重置用户密码】：选择用户 → 设置新密码；**不可给自己重置**，重置后该用户全部会话立即失效；

4）【批量套用默认存储配额】：把当前默认配额写到所有已有空间；

5）【平台 API Key】：签发控制面自动化密钥（系统空间读写、系统设置读写、运行参数读写、审计读取四类能力）。

#### 2.9.4. 系统审计日志

**功能描述**

平台级操作留痕：改全局设置、提升/撤销管理员、任务队列操作、重置密码等。

**操作方法**

1）【系统控制台】→【系统审计日志】；

2）按时间/操作人/事件类型筛选；

3）空间级事件（成员变更、文档操作）在**空间设置 → 审计日志**查看（见 2.10.1）。

### 2.10. 审计与运维

#### 2.10.1. 审计日志

**功能描述**

两级审计：空间级（谁在何时对空间做了什么）+ 平台级（2.9.4）。

**操作方法**

1）【空间设置】→【审计日志】：查看成员/角色变更、配置修改等空间级事件，按时间与操作人筛选；

2）知识库设置 →【活动】：查看该库下"谁在何时做了什么"（上传、删除、改配置、编辑分块、Wiki 变更）；

3）数据争议或权限审计时，按 空间审计（人）→ 库活动（物） 两级追溯。

#### 2.10.2. 可观测性（Langfuse）

**功能描述**

全链路追踪：每次问答/Agent 执行/模型调用/文档解析的耗时与 Token 成本（可自建部署，数据不出域）。

**操作方法**

1）【系统控制台】→【可观测性】查看接入状态，跳转 Langfuse 控制台；

2）按会话/用户检索追踪链：`agent.execute → 每轮推理 → 每步工具调用`，含 Token 用量与输出预览；

3）LLM / 向量 / 重排 / 视觉 / 语音每次调用与耗时分段可见；

4）文档【解析追踪时间线】：逐阶段 Span 树（解析 → 分块 → OCR → 图片描述 → 向量化），定位卡住阶段，可中止解析；

5）Token 成本核算：按模型/Agent 维度聚合统计。

#### 2.10.3. 日常运维巡检清单

## 3. 常见问题

**Q1：新成员建库失败，提示配额不足或模型未配置？**

A：① 空间存储配额已满——调大配额或清理旧库；② 空间还没有向量模型——先完成 2.2 模型管理，再建库。

**Q2：换过向量模型后，老数据检索不到了？**

A：向量模型决定索引语义空间，更换后必须重建索引。处理方式：整库重新解析，或整库复制后在新模型下重建。因此请遵守"建库后不换向量模型"原则。

**Q3：扫描件/PDF 表格解析效果差？**

A：① 扫描件无文字：配置视觉模型（VLM）并勾选图片理解，重新解析；② 表格错位：库分块配置中为 pdf/xlsx 指定解析引擎（MarkItDown / OpenDataLoader / MinerU），Excel 打开"首行作为表头"，重新解析。

**Q4：改了环境变量但没生效？**

A：系统设置中改过的项**数据库值优先于环境变量**。在系统设置中把该项【重置】（删除数据库覆盖）即回落到环境变量。

**Q5：数据源同步失败/数据没进来？**

A：查看同步日志的失败样本（可读原因）。最常见是凭据过期——重新授权即可；大规模同步超时走断点续传，无需重来。

**Q6：IM 机器人突然不回复？**

A：① 平台凭据过期或被改动，更新后重启渠道；② webhook 模式的回调地址变更；③ 多实例部署下长连接 leader 切换（看 app 日志）；④ 绑定 Agent 的知识库被删或模型不可用。

**Q7：访客通过官网挂件能问到非客服内容吗？**

A：不能。渠道只能访问**绑定 Agent 的知识库范围**内的内容，会话按渠道隔离。发现异常先核对绑定的 Agent 与知识库范围、白名单、限流触发记录。

**Q8：Agent 调 MCP 工具失败？**

A：① 服务连通性测试；② OAuth 类授权过期，用户在会话内重新授权；③ 危险工具开启了人工审批被阻塞或拒绝；④ 检查该 Agent 的工具勾选是否包含该工具。

**Q9：解析一直卡在"处理中"？**

A：① 大文件/数百页扫描件属正常，看解析追踪时间线确认所处阶段；② 任务队列面板看是否失败或积压，失败任务点重试；③ 扫描件确认视觉模型已配置。

**Q10：我明明是所有者，为什么看不到系统控制台？**

A：系统控制台属于**平台级系统管理员**，与空间所有者是两个独立身份。请让现有系统管理员在 2.9.3 中提升你，或部署时通过 `WEKNORA_BOOTSTRAP_SYSTEM_ADMIN_EMAIL` 指定。

**Q11：共享给我的库为什么改不了？**

A：三选一原因：① 共享时给的是只读；② 源空间归属规则限制（源库仅管理员可写时外部一律只读）；③ 你所在空间以"只读"身份加入组织。

**Q12：升级后功能有异常怎么回滚？**

A：`docker compose` 将 `.env` 中 `WEKNORA_VERSION` 改回上一版本，`docker compose pull && up -d` 回滚。数据库迁移默认自动执行且向后兼容；**升级前务必备份数据卷**（切勿用 `down -v` 重置数据）。
