# 7. 权限安全与运维

本章覆盖：空间内权限（RBAC）与成员管理、跨空间共享组织、API Key、平台级系统管理员、数据安全机制、模型与存储配置、系统运维面板。

---

## 7.1 权限模型总览

系统有**两条正交的权限线**，一次跨空间写操作要同时穿过两道闸口：

| 维度 | 解决什么 | 角色 |
|------|---------|------|
| **空间 RBAC（纵向）** | 同一空间内"你能对自己/别人/公共资源做什么" | Owner / Admin / Contributor / Viewer |
| **共享组织（横向）** | 跨空间"把我的知识库/Agent 让别的空间的人用" | 管理员 / 编辑者 / 只读 |

另有两个独立身份：

- **系统管理员（System Admin）**：平台级，管整个部署（§7.8），不属于任何空间；
- **跨空间超管（CanAccessAllTenants）**：可读写他人空间数据的高级身份，需显式开启。

## 7.2 空间四级角色

| 角色 | 典型场景 | 关键能力 |
|------|---------|---------|
| **Owner 所有者** | 空间负责人 | Admin 全部权限 + 删除空间、转让；每空间至少 1 人、可多人 |
| **Admin 管理员** | 空间运维 | 管理成员；配置模型/向量库/IM/嵌入等公共基础设施；变更空间内**任意**资源 |
| **Contributor 编辑者** | 知识维护者 | 创建并维护**自己**的知识库与 Agent（他人库等同 Viewer）；上传文档、编辑分块、管 FAQ |
| **Viewer 查看者** | 只读使用者 | 浏览、提问、读 Wiki（不可发起任何变更） |

### 资源归属（谁的库谁能改）

关键资源（知识库、Agent、分块、FAQ 条目、Wiki 页面）都记录**创建者**：

- Contributor：**自己的资源**里等同 Owner，**别人的资源**等同 Viewer；
- `creator_id` 为空的"空间共有"资源仅 Admin+ 可变更；
- 角色变更在空间设置 → 成员 中操作；降级/移除时系统保护"至少保留一位 Owner"。

> 角色阶梯：`viewer < contributor < admin < owner`，高角色继承低角色全部权限。

## 7.3 成员管理与邀请

「空间设置 → 成员」：

1. **邀请**：填邮箱 + 选角色 → 发送邀请（状态 pending）；
2. 被邀请人接受后成为正式成员（状态 active）；
3. 管理员可调整角色、挂起（suspended）、移除成员；
4. **注册模式**（空间设置 → 系统）：
   - `self_serve`（默认）：任何人可注册并自动建个人空间；
   - `invite_only`（**团队部署推荐**）：关闭公开注册，新用户必须经邀请加入；
5. **自助建空间**：可控制用户能否自己建空间、最多拥有几个空间、每个空间默认配额（GB）。

## 7.4 跨空间共享（组织 Organization）

**用途**：把某个知识库或 Agent 以只读 / 可写权限共享给另一个空间（比如"产品部把产品文档库共享给客服部"）。

步骤：

1. 创建一个**组织**（跨租户协作单元，邀请码加入）；
2. 把两个空间都加入组织（空间以 管理员/编辑者/只读 身份加入）；
3. 在知识库上「共享到组织」，选择共享范围与权限（只读 / 可写）；
4. 目标空间的成员即可在知识库列表看到并使用该库。

**要点**：

- 共享不改变资源归属——库仍属原空间，创建者不变；
- "可写"共享 ≠ 外部空间能随便改：**源空间里的归属规则仍然生效**（例如源空间只允许 Admin 改的库，外部共享也只能读）;
- 取消共享立即生效，已复制的副本不受影响。

## 7.5 API Key（机器身份）

「空间设置 → API Key」为程序化访问签发凭证：

| 特性 | 说明 |
|------|------|
| 作用域 | 空间级（tenant）：在该空间内拥有等同 Admin 的能力（删空间除外）；平台级（platform）：控制面自动化（见 §7.8） |
| 细粒度能力 | `retrieve` / `chat` / `ingest` / `manage_kbs` / `manage_models` / `message_history` 等，按最小够用原则勾选 |
| 知识库限定 | 可用 `KnowledgeBaseIDs` 把 Key 锁定在指定库，访问范围外直接拒绝 |
| 审计与节流 | 记录 last_used、支持节流追踪 |
| 安全 | Key 落库 AES-256-GCM 加密；支持平滑密钥轮换；撤销立即失效 |

> 调试：空间设置内置 **API 集成调试台**，可直接在线填参数试跑端点，不用切到 Postman。

## 7.6 数据安全机制（部署方须知）

| 机制 | 说明 |
|------|------|
| **凭据静态加密** | API Key、MCP 凭据、数据源密码等敏感字段 AES-256-GCM 落库；`SYSTEM_AES_KEY` 支持平滑轮换 |
| **服务间通信加密** | app ↔ docreader 走 gRPC TLS + Token；Redis 可开 TLS |
| **SSRF 防护** | 所有外部抓取（数据源、URL 导入、嵌入 Webhook、重定向链）经防 SSRF 客户端，禁止内网/链路本地地址；搜索引擎端点硬编码不可被租户改写 |
| **密钥响应脱敏** | API 返回中敏感字段一律不回显（只返回"已配置"布尔） |
| **技能沙箱** | Agent Skills 脚本在一次性 Docker 容器中执行，非 root，与主系统隔离 |
| **OIDC 单点登录** | 支持企业 IdP（如 Dex/Keycloak）统一认证 |
| **邀请制准入** | `invite_only` 模式下杜绝陌生人注册；无空间预置 + 受控自助建空间策略 |
| **会话吊销** | 管理员重置用户密码后，其全部会话立即失效 |

## 7.7 模型管理

### 五类模型

| 类型 | 用途 | 配置位置 |
|------|------|---------|
| **对话 LLM** | 问答、推理、摘要、问题生成、图谱抽取 | 全局添加 → 按知识库/Agent 选用 |
| **向量 Embedding** | 文本向量化（决定索引维度与含义） | **建库后不可换**（需重建索引） |
| **重排 Rerank** | 检索结果精排，提升答案准确性 | 强烈建议开启 |
| **视觉 VLM** | 图片理解、扫描件描述 | 开图片理解 / 扫描件解析时配置 |
| **语音 ASR** | 音频转写 | 需解析音频文件时配置 |

### 支持的厂商（26 家抽象层，含本地）

本地 **Ollama**（完全离线）+ OpenAI、Azure OpenAI、Anthropic Claude、Gemini、DeepSeek、Qwen（阿里云）、智谱、混元、豆包（火山引擎）、MiniMax、月之暗面（Kimi）、SiliconFlow、百度千帆、OpenRouter、Requesty、Jina、NVIDIA、GPUStack（私有化）、腾讯云 LKEAP、Novita AI、WeKnora Cloud 等。任何 **OpenAI 兼容接口**（`generic`）均可接入。

### 管理操作（设置 → 模型）

- 添加模型：选类型 → 选厂商（或通用兼容）→ 填 Base URL + API Key + 模型名 → **点测试**再保存；
- 支持按模型覆盖：思考模式开关、Embedding 维度等；
- **YAML 声明式内置模型**（`config/builtin_models.yaml`）：预置一批开箱模型供全空间共享；
- 交互式**模型调试器**：不建库先试问，验证模型可用性；
- 模型并发治理：平台级按模型并发上限（默认 32），防止单模型被打爆；
- WeKnora Cloud：托管模型与托管解析（可选商业能力）。

> **选型经验**：对话用强推理模型；向量选 bge-m3 / gte 类中文强的模型；Rerank 开 bge-reranker 或火山引擎 Rerank 性价比最高。本地 + 远程可混用（如本地小模型做向量化，远程大模型做回答）。

## 7.8 向量库 / 检索引擎与对象存储

### 检索引擎（10 种后端）

| 引擎 | 适用 |
|------|------|
| **PostgreSQL（ParadeDB，默认）** | 向量 + BM25 关键词一体，与业务同库，**绝大多数部署无需换** |
| SQLite | 单机 / 桌面版，零依赖 |
| Elasticsearch / OpenSearch | 复用公司现有 ES 栈 |
| Qdrant / Milvus / Weaviate / Apache Doris / 腾讯云 VectorDB | 千万级向量独立扩容 / 特定云环境 |

> 换引擎需重建索引；建库后知识库绑定的向量存储**不可更改**。多实例：可在「设置 → 向量存储」注册多个实例，**按知识库绑定**不同实例（数据隔离/性能隔离场景）。

### 对象存储（8 种）

本地 / 腾讯云 COS / 火山引擎 TOS / MinIO / AWS S3（支持 IAM Role / IRSA 默认凭据链）/ 阿里云 OSS / 金山云 KS3 / 华为云 OBS。

同样支持**每空间多实例**：不同知识库绑定不同存储实例，可设默认实例。

## 7.9 平台管理与系统管理员

> **先划清界限**：空间 Owner 管一个空间；系统管理员管**整个部署**。两者互不叠加。

### 控制台（设置侧栏底部，仅系统管理员可见）

| 分区 | 能力 |
|------|------|
| **系统设置** | 全局运行时开关：注册模式、空间策略、各 Worker 池并发、模型并发上限、SSRF 白名单等；**改完立即生效，不用重启**；数据库值盖过环境变量 |
| **任务队列** | 查看各队列实时积压（core / 后处理 / enrichment / maintenance / 弹性共享 / Wiki 独立池）；任务级重试/归档/删除；批量清空归档 |
| **平台 API Key** | 控制面自动化专用 Key：`system_tenants_read/manage`、`system_settings_read/manage`、`system_runtime_read/manage`、`system_audit_read` |
| **系统审计日志** | 平台级事件：改设置、提升/撤销管理员、队列操作（空间级事件在空间审计里看） |

### 其他平台级能力

- **提升 / 撤销系统管理员**：不可撤销自己、不可撤销最后一个管理员（保险机制）；
- **重置用户密码**：替换密码并**吊销其全部会话**；不能给自己重置；
- **批量套用默认存储配额**：把当前默认配额写到所有已存在空间。

### 可观测性（Langfuse）

- 每次问答、Agent 执行生成完整追踪链：`agent.execute → agent.round.N → agent.tool.<name>`，含每轮 Token 用量、工具输出预览；
- LLM / Embedding / Rerank / VLM / ASR 每次调用与耗时分段可见；
- 文档**解析追踪时间线**（Langfuse 风格 Span 树）：逐阶段进度，可中止解析;
- Langfuse 可完全自建（`docker compose --profile langfuse up -d`），数据不出域。

## 7.10 审计与任务运维（日常巡检清单）

| 看什么 | 在哪里 | 何时看 |
|--------|--------|--------|
| 谁改过空间（成员/角色变更） | 空间设置 → 审计日志 | 定期合规检查 |
| 谁动过某知识库 | 知识库设置 → 活动 | 数据争议时追溯 |
| 解析为什么失败 | 文档解析追踪时间线 + 任务队列面板 | 文档卡在"处理中/失败" |
| 队列是否堆积 | 系统管理员 → 任务队列 | 高峰期 / 大批量上传后 |
| Token 成本 | Langfuse 追踪 | 成本核算 |
| 渠道会话质量 | 会话列表按 IM/嵌入/API 分组（Admin+） | 排查对外服务质量 |

> 所有异步任务（解析、向量化、Wiki、图谱、数据源同步）失败都会进入失败队列并**自动重试**，重试耗尽进入死信——在任务队列面板可手动重试，保障"不丢任务"。
