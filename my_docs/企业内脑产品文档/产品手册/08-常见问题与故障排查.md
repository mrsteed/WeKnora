# 8. 常见问题与故障排查

## 8.1 使用类 FAQ

**Q1：答案里带引用，但我不确定答案是不是瞎编的？**
A：点引用角标跳到原文分块对照。企业内脑的 RAG 回答都基于检索片段生成；引用面板中找不到依据来源的论断要警惕。开启 Rerank、调优分块能显著提升质量。引用角标开关（`citation_enabled`）只控制正文显示，不改变检索行为。

**Q2：快速问答和智能推理到底怎么选？**
A：答案"就在文档里"的事实性问题用快速问答（快、省）；需要"跨多个文档综合 + 联网 + 调工具"的复杂问题用智能推理。不确定就先快后慢：快速问答不满意再切推理。

**Q3：为什么换了向量模型后老数据搜不到了？**
A：向量模型决定索引里向量的"语言"，换模型后新旧向量不在同一语义空间。必须重建索引（全量重新解析，或复制一个新库）。**所以建库时选好的向量模型不要再换**。

**Q4：文档一直在"处理中"动不了？**
A：① 大文件/数百页扫描件本来就慢（可看解析追踪时间线确认它在哪个阶段）；② 检查任务队列面板是否有积压或失败；③ 查看失败原因后手动重试；④ 扫描件确保配置了视觉模型。

**Q5：同一个机器人怎么在两个群里答得不一样？**
A：IM 会话按"平台+用户+群"隔离，上下文互不串。若同一问题答案不一致，通常是知识库范围（绑定的 Agent 配置）或数据源同步时间差导致。

**Q6：访客能通过嵌入 Widget 看到我其他知识库的内容吗？**
A：不能。渠道绑定哪个 Agent，就只能用哪个 Agent 知识库范围内的内容；且会话、图片引用都按渠道隔离鉴权。

**Q7：API Key 能限死只能访问某几个知识库吗？**
A：能。建 Key 时用 `KnowledgeBaseIDs` 限定，越权请求直接拒绝。

**Q8：Wiki 生成要多久？贵吗？**
A：异步生成，成本与文档量成正比（每篇文档多次 LLM 调用）。用"聚焦"粒度试水、核心库用"标准"，"详尽"仅用于小范围高价值库。

**Q9：我删了知识库，数据还能找回吗？**
A：删除是级联清理（知识/分块/索引/文件），不可恢复。请用「整库复制」做备份，或先导出再删。

**Q10：怎么控制"谁能用我建的 Agent"？**
A：Agent 有"允许查看者运行"开关（默认开）；关掉后需编辑者及以上角色。知识库范围决定了它能查什么。

## 8.2 部署与启动类

**Q1：启动后前端打不开 / 白屏？**
A：按顺序排查：
```bash
docker compose ps                     # 确认 frontend/app/postgres/redis 都 healthy
curl http://localhost:8080/health     # 后端就绪？
docker compose logs app --tail 100    # 后端报错？
```
常见原因：`.env` 必填项没改（DB/Redis 密码、JWT_SECRET、SYSTEM_AES_KEY）导致依赖服务起不来；`FRONTEND_PORT` 被占用。

**Q2：容器内连本地 Ollama 连不上？**
A：模型 Base URL 填 `http://host.docker.internal:11434`，**不是** `localhost`（容器内 localhost 是容器自己）。

**Q3：升级后界面显示的版本不对？**
A：`docker compose up -d` 会复用本地缓存镜像。升级必须 `docker compose pull` 后再 `up -d`，并注意 `.env` 中 `WEKNORA_VERSION`。

**Q4：数据库迁移失败？**
A：默认 `AUTO_MIGRATE=true` 启动时自动迁移。失败时看 `docker compose logs app` 中 migrate 段输出；可手动 `make migrate-up`。切勿手工改表结构。

**Q5：改了环境变量不生效？**
A：系统设置中改过的键**数据库值盖过环境变量**——在系统管理员控制台把该设置项重置（删除 DB 行）即回落到环境变量。排查"改了 env 没反应"先查这里。

**Q6：如何干净地重置整个部署（数据全删）？**
A：`docker compose down -v` 会连数据卷一起删（Postgres/Redis/MinIO 数据全丢），执行前务必备份。`make clean-db` 是同类危险操作。

## 8.3 解析质量类

| 症状 | 处理 |
|------|------|
| PDF 版式混乱、表格错位 | 库解析设置为 `pdf` 指定引擎（MarkItDown / OpenDataLoader / MinerU） |
| 扫描件没出字 | 配置并启用视觉模型（VLM） |
| Excel 首行列名被当数据 | 为 `xlsx`/`xls` 打开"首行作为表头" |
| 个别段落切错 | 不必重传：打开文档 → 分块列表直接改分块（自动重建索引） |
| 图片内容问不到 | 确认 VLM 已配置且该文档在启用 VLM 后重新解析 |
| 音频解析没内容 | 确认 ASR 模型已配置 |

> 解析/分块调整后对受影响文档执行**重新解析**才生效；支持批量重新解析。

## 8.4 检索与答案质量调优路线

按性价比从高到低依次尝试：

1. **开启 Rerank 重排**（多数场景收益最大，成本增加最小）；
2. **人工校对高频文档的分块与生成问题**（改错字、合并碎块、补预生成问题）；
3. **固定答案改做 FAQ 库**（制度、流程、常见报错，直接命中标准答案）;
4. **调分块参数**：长文档开父子分块；条目式资料重叠设 0、按行/段落分隔；
5. **问题预生成**打开，提升口语化提问召回；
6. 关系密集资料开**知识图谱**；零散资料开 **Wiki** 让 Agent 多一条导航路径；
7. 检索阈值调参（租户级 `RetrievalConfig`：向量阈值、关键词阈值、Rerank TopK 等），默认值先别动，有召回率/准确率评测后再调。

## 8.5 权限类

**Q1：我是 Owner，为什么"系统设置/任务队列"看不到？**
A：那是**平台级**系统管理员功能，空间 Owner 看不到。用 `WEKNORA_BOOTSTRAP_SYSTEM_ADMIN_EMAIL` 指定第一个系统管理员，或让现有系统管理员在控制台提升你。

**Q2：Contributor 建不了库？**
A：检查空间存储配额是否已满，以及 Embedding 模型是否已配置（建库校验会拦）。

**Q3：共享给我的库为什么改不了？**
A：① 共享时给的是"只读"；② 源空间的归属规则限制（源库仅 Admin+ 可写时，外部共享一律只读）；③ 你的组织内角色是"只读"。三个条件都满足才可写。

**Q4：API Key 调用被 403？**
A：Key 能力没勾对应操作（如入库需 `ingest`），或 Key 限定了知识库范围而请求越界。

**Q5：重置了某人密码，他为什么被踢下线了？**
A：预期行为——重置密码会吊销该用户全部会话（安全机制）。

## 8.6 错误码与日志速查

| 现象 | 定位 |
|------|------|
| SSE 问答中断无回答 | 看进度条是否停在"正在生成回答"超过 60s（停滞态）；Langfuse 追踪该请求的 LLM 调用是否超时；按 Agent 配置可调 LLM 调用超时 |
| IM 机器人失联 | 渠道凭据过期/被改；平台回调地址变更；多实例下 leader 切换（看 app 日志 leader 选举记录） |
| 嵌入 Widget 突然不可用 | 渠道被禁用 / 令牌被轮换 / 白名单变更 / 触发限流；用预览会话功能验证配置 |
| 数据源同步失败 | 看 SyncLog 的失败样本（i18n 可读原因）；凭据过期时 UI 显示"凭据未配置"，重填即可 |
| MCP 工具调用失败 | 服务连通性测试；OAuth 类看是否过期需重新授权；危险工具是否被审批阻塞 |
| 接口 429 | API Key 触发节流，或嵌入渠道触发限流 |

## 8.7 求助路径

1. `docker compose logs <服务>` 看组件日志（app 为主）;
2. Langfuse 查单次请求全链路（哪一步失败、耗在哪）;
3. 任务队列面板查异步任务状态与重试;
4. Swagger（debug 模式）确认接口契约;
5. 仍无法解决：记录 版本号 + 报错原文 + 请求参数（脱敏后），提交 Issue 或联系部署支持。

> 提交问题前请**脱敏**：API Key、凭据字段切勿外发。系统响应本身已做密钥脱敏，但请检查请求体与日志摘录。
