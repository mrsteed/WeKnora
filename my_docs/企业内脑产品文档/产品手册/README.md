## 一、产品简介

**IntraMind 企业内脑**是一款基于大语言模型（LLM）的企业级知识管理平台，把散落在企业各处的文档（PDF、Word、表格、网页、飞书/Notion/语雀内容等）沉淀为一个**能回答、能推理、能自生长**的"知识大脑"。

### 1.1 三大核心模式

| 模式 | 解决什么问题 | 典型场景 |
|------|-------------|---------|
| **智能问答** | 员工提问，秒级从知识库中找到带出处的答案 | 制度查询、产品参数、操作指引 |
| **智能推理** | 复杂问题由 Agent 自动拆解、多轮检索、调用工具、联网搜索后给出结论 | 合同条款对比、合规审查、方案调研 |
| **自动 Wiki** | Agent 从原始文档自动抽取结构化 Wiki 页面与知识图谱，知识库"自己长出来" | 新人上手、领域知识体系化沉淀 |

### 1.2 功能总览

| 模块 | 能力 |
|------|------|
| 知识接入 | 文件上传、URL 导入、手写条目、文件夹树；12+ 文档格式（PDF/Word/Excel/PPT/图片/EPUB/音频…）；飞书/Notion/语雀/RSS 定时自动同步 |
| 知识加工 | 独立文档解析服务（版式分析/OCR/表格/图片理解/语音转写）；智能分块（含父子分块与自适应策略）；分块可视化编辑与版本回滚；文档标签与自定义元数据 |
| 智能问答 | 混合检索（向量 + 关键词 BM25 + 重排，可选知识图谱增强）；引用溯源浮层；推荐问题与追问；临时附件一次性问答；对话 Markdown 导出 |
| 智能体 Agent | 内置快速问答 / 智能推理 / 数据分析 / Wiki 研究员等 Agent；自定义 Agent（模型、知识范围、联网搜索、MCP 工具、技能、提示词均可配） |
| 工具生态 | 内置 24 个工具（知识检索、Wiki 读写、数据分析 DuckDB SQL、网页抓取等）；MCP 外部工具接入（含 OAuth2、危险操作人工审批）；Agent Skills 沙箱执行 |
| 自动 Wiki | 从文档自动生成相互链接的 Markdown 百科页面与知识图谱；人工编辑、逐版本 diff、一键回滚 |
| 多渠道发布 | Web 端、企业微信/飞书/钉钉/Slack/Telegram/微信/QQ/云之家等 10 个 IM 平台、网站嵌入 Widget、微信小程序、Chrome 插件 |
| 权限与安全 | 空间四级角色（Owner/Admin/Contributor/Viewer）+ 按知识库资源归属 + 跨空间共享组织 + 空间审计日志；凭据 AES-256 加密；SSRF 防护；技能沙箱隔离 |
| 模型与存储 | 20+ 大模型厂商可选（LLM/Embedding/Rerank/VLM/ASR 五类）；8 种向量/检索后端；本地/COS/TOS/S3/OSS 等 8 种对象存储 |
| 运维可观测 | Langfuse 全链路追踪；运行时任务队列面板 + Worker 池治理；解析进度时间线 |

### 1.3 核心概念速览

| 概念 | 一句话解释 |
|------|-----------|
| **工作空间（空间/租户）** | 资源隔离与配额（默认 10GB）的基本单位；知识库、模型、Agent、会话都归属某个空间 |
| **成员与角色** | Owner（所有者）> Admin（管理员）> Contributor（编辑者）> Viewer（查看者） |
| **知识库** | 知识容器，三种类型：文档 / FAQ / Wiki；决定这批资料怎么切分、用什么模型索引 |
| **知识** | 库里的一条内容：一个文件、一个网页、一段手写 Markdown 或一组 FAQ 问答对 |
| **分块（Chunk）** | 文档被切分成的检索最小单元；可编辑、可打版本、可回滚 |
| **智能体（Agent）** | 配置好"用什么模型、查哪些库、能否联网、挂哪些工具"的问答角色；内置 + 自建 |
| **会话** | 一次多轮对话；跨渠道（Web/IM/嵌入/API）统一管理 |
| **模型** | 对话 LLM、向量 Embedding、重排 Rerank、视觉 VLM、语音 ASR 五类，按知识库/Agent 选用 |
| **组织（共享空间）** | 跨空间的协作单元，把知识库/Agent 以只读或可写权限共享给其他空间 |
