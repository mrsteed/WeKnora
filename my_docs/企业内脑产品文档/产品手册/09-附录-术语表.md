# 9. 附录：术语表

按域分组，首次阅读时遇到生词可回查此处。

## 9.1 平台与租户

| 术语 | 说明 |
|------|------|
| **Tenant / 工作空间** | 多租户隔离单元，数据、成员、模型配置、存储配额均按空间隔离 |
| **Owner / Admin / Contributor / Viewer** | 空间四级角色（所有者/管理员/编辑者/查看者），阶梯继承 |
| **资源归属（creator_id）** | 关键资源记录创建者；编辑者"自己的资源"全权、"别人资源"只读 |
| **共享组织（Organization）** | 跨空间协作单元：把库/Agent 跨租户共享的通道 |
| **系统管理员（System Admin）** | 平台级身份：管全局设置、任务队列、平台 API Key、审计、管理员管理，不叠加空间权限 |
| **跨空间超管（CanAccessAllTenants）** | 可读写他人空间数据的高级身份（需显式开启，高危） |
| **邀请制（invite_only）** | 关闭公开注册，新用户仅可经邀请加入 |
| **存储空间配额（Storage Quota）** | 按空间计的文件/分块用量上限，配额满则上传被拒 |
| **API Key** | 程序化访问凭证；分空间级与平台级，支持细粒度能力与知识库范围限定 |
| **会话吊销** | 重置密码/登出后全部已签发会话失效的安全机制 |

## 9.2 知识库与文档

| 术语 | 说明 |
|------|------|
| **KnowledgeBase / 知识库** | 资料容器；三种类型：document（文档）/ faq / wiki |
| **Knowledge / 知识** | 库内一条原始资料（一个文件、一个 URL、一条 FAQ） |
| **Chunk / 分块** | 文档切分后的小段单元，是检索与引用的最小单位；含预生成问题、摘要、FAQ 子项 |
| **分块策略** | auto / heading / heuristic / recursive / legacy（按大小/标题/语义边界/递归分割/旧逻辑） |
| **父子分块** | Parent 大块负责语义完整，Child 小块负责精确检索；Parent-Child 模式按 Child 检索、按 Parent 呈现 |
| **chunk_size / overlap** | 分块目标字数与相邻块重叠字数 |
| **重新解析（Reparse）** | 换解析配置后对存量文档重新走解析流水线（支持批量） |
| **解析状态机** | pending → processing → finalizing → completed；可 failed / cancelled |
| **解析追踪时间线（Parse Timeline）** | Langfuse 风格的解析阶段 Span 树，定位卡住/失败原因 |
| **FAQ 知识库** | 直配的"问题→答案"集合，支持单条/Excel 导入、命中即直出 |
| **数据源（DataSource）** | 周期性把外部内容拉进库：飞书/Lark Wiki、Notion、语雀、RSS |
| **同步范围** | 全量 / 按知识库目录（Feishu） |
| **整库副本（Copy）** | 同空间内对知识库及其文档、分块、索引的深拷贝 |
| **索引构建状态 / 进度** | 库级向量/关键词索引构建的异步状态与百分比 |

## 9.3 检索与问答

| 术语 | 说明 |
|------|------|
| **混合检索（Hybrid Search）** | 向量语义检索 + BM25 关键词检索并行执行后融合 |
| **RRF（Reciprocal Rank Fusion）** | 按排名（非分数）融合两路结果的算法，默认 K=60 |
| **向量 / 关键词 / 融合权重** | VectorThreshold / KeywordThreshold / Weights（默认 0.7/0.3），决定进入重排前的候选 |
| **Rerank 重排** | 用 Rerank 模型对融合候选精排，取 Top 与阈值过滤 |
| **Embedding 向量模型** | 文本转向量；**建库后不可更换**（需重建索引） |
| **VLLM / VLM 视觉模型** | 图片与扫描件理解 |
| **ASR** | 音频转写模型 |
| **快速问答（Quick Answer）** | 单轮 RAG：检索→拼接→生成，带引用 |
| **智能推理（Smart Reasoning）** | ReAct Agent 多轮工具调用范式（检索、联网、MCP、技能等） |
| **Agent / 智能体** | 把模型 + 知识库范围 + 提示词 + 工具打包的可复用问答配置 |
| **内置 Agent** | 预置问答模板（quick-answer / smart-reasoning） |
| **MCP 客户端** | Agent 作为 MCP 消费者挂载外部工具服务的配置 |
| **MCP Server（企业内脑侧）** | 把企业内脑能力以 29 个工具**暴露**给外部 MCP 客户端 |
| **Skill / 技能** | Agent 可挂载的脚本化能力包（如 PDF/Excel/Word 处理、PPT 生成、可视化图表），在一次性沙箱容器执行 |
| **SSE（Server-Sent Events）** | 问答接口流式返回协议（token 逐字推送 + 阶段事件） |
| **引用（Citation）** | 回答中带角标的证据来源，悬停预览、点击打开原文 |
| **临时附件** | 仅对当前提问生效的文件/图片，不入库 |
| **推荐问题（Suggestions）** | 会话空闲时基于知识库生成的后续问题建议 |
| **联网检索（Web Search）** | Agent 调用外部搜索引擎（默认 SearXNG，可换）补充实时信息 |
| **问题预生成 / 摘要** | 解析完成后自动为分块生成口语化问题与摘要，提升召回 |
| **RRF 候选数（EmbeddingTopK 等）** | 检索配置中的各阶段截断参数 |
| **RRF TopK=10、Rerank 阈值 0.2 等默认值** | 全平台检索默认参数（`internal/types/constant.go`） |

## 9.4 Wiki 与图谱

| 术语 | 说明 |
|------|------|
| **自动 Wiki** | 从文档批量生成结构化 Wiki 页面 |
| **Wiki 页面类型** | overview / entity / index / topic / comparison / summary 等 |
| **生成粒度** | focused / standard / detailed（LLM 调用量递增） |
| **页面版本** | 每次编辑自动留版本快照，可对比、可回滚 |
| **知识图谱（KG）** | 从文档抽取实体与关系构成的图结构（Entity / Relationship / 边） |
| **GraphRAG** | 图上问答检索（路径推理、关系召回），独立于向量库 |
| **wiki / graph 索引开关** | 知识库级两个异步构建开关（独立启停，可并行） |

## 9.5 渠道

| 术语 | 说明 |
|------|------|
| **嵌入渠道（Embed Channel）** | 官网 Widget 的免登录会话通道（令牌 `em_` 前缀） |
| **域名白名单** | 限制 Widget 可嵌入的 Origin（支持 `*.` 子域匹配；生产禁用全通配） |
| **限流（Rate Limit）** | 嵌入渠道单 IP 每分钟上限 + 渠道每日总量上限 |
| **IM 渠道（IMChannel）** | 企业微信/飞书/Slack 等 10 个 IM 平台的机器人绑定 |
| **接入模式** | websocket（默认，免公网）/ webhook（需公网回调）/ 长轮询 |
| **会话模式** | `user`（按人+群维持上下文）/ `thread`（按线程隔离） |
| **文件入库知识库** | IM 渠道可绑定的库，用户发来的文件/图片自动入库 |
| **CLI** | `weknora` 命令行工具（问答/知识管理，NDJSON 流式，`--dry-run` 预览） |

## 9.6 模型、存储与运行时

| 术语 | 说明 |
|------|------|
| **五类模型** | 对话 LLM / 向量 Embedding / 重排 Rerank / 视觉 VLLM / 语音 ASR |
| **模型厂商抽象层** | 26 家厂商 + Ollama 本地，OpenAI 兼容接口统称 generic |
| **内置模型（builtin_models）** | 随部署内置、全空间共享的 YAML 预置模型 |
| **向量检索引擎（10 种）** | PostgreSQL（ParadeDB，默认）/ SQLite / Elasticsearch / OpenSearch / Qdrant / Milvus / Weaviate / Apache Doris / 腾讯云 VectorDB / Neo4j（图谱） |
| **对象存储（8 种）** | 本地 / MinIO / 腾讯云 COS / 火山引擎 TOS / AWS S3 / 阿里云 OSS / 金山云 KS3 / 华为云 OBS；支持每空间多实例按库绑定 |
| **StorageProviderConfig** | 对象存储的 8 字段凭据模型（bucket/endpoint/access_key 等），落库 AES 加密 |
| **docreader** | 独立文档解析服务（Python + gRPC），把各类文件转 Markdown 分块 |
| **Asynq（任务队列）** | 解析/向量化/Wiki/图谱等异步任务的队列框架（Redis 后端），Worker 池 + 失败重试 |
| **队列池** | core / postprocess / enrichment / maintenance / shared（弹性共享）/ wiki 等，并发可在控制台实时调整 |
| **死信 / 重放** | 重试耗尽的任务归档死信队列，支持手动重放 |
| **Langfuse** | 可观测平台：LLM 调用链、Token 成本、解析追踪时间线全量接入 |
| **AUTO_MIGRATE** | 启动时自动执行数据库迁移（默认开） |
| **DB 覆盖 env** | 运行时设置：数据库存储的值优先于环境变量，改 env 不生效时的排查点 |
| **SSRF 白名单** | 平台全局允许抓取的内网地址例外清单（默认空 = 全禁） |
| **资源直链模式（RESOURCE_URL_MODE=public）** | 文件/图片以公开直链返回，免二次鉴权代理 |

## 9.7 安全与审计

| 术语 | 说明 |
|------|------|
| **AES-256-GCM 密钥** | 敏感凭据落库加密密钥（SYSTEM_AES_KEY），支持平滑轮换 |
| **SSRF 防护** | 对外抓取禁内网地址 + 搜索引擎端点硬编码 |
| **OIDC** | 企业单点登录认证 |
| **技能沙箱** | 技能脚本在一次性 Docker 容器执行（非 root、临时容器） |
| **审计日志** | 两个层级：空间级（谁改了什么空间）与平台级（系统管理员操作） |
| **MCP 危险工具审批策略** | deny / ask / allow 三档，拦截高风险外部工具调用 |
| **会话级审批** | 审批事件随问题流回前端/IM，用户确认后代为执行 |
