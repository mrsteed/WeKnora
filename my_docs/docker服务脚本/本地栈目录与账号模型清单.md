# 本地栈目录与账号模型清单

## 1. 三个目录的关系

### 1.1 /data/docker/volumes

- 这是 Docker daemon 自己维护的 named volume 落盘目录。
- 当 compose 使用 `postgres-data`、`minio_data` 这类 named volume，而不是宿主机 bind mount 时，真实数据最终会落到这里。
- 这个目录不应该手工当业务数据根目录来维护；它只是 Docker 的内部存储区。

### 1.2 /data/weknora

- 这是 WeKnora 本地部署的宿主机总根目录。
- 其中当前约定把业务栈数据统一放到 `/data/weknora` 根目录本身。
- 模型服务不并入这个规则：模型缓存和模型文件继续放在 `/data/models`，视觉模型日志保留在 `/data/weknora/model-logs`。

### 1.3 /data/weknora/dev

- 这是已经清理掉的历史遗留目录。
- 业务栈默认已切回 `/data/weknora`，旧的 `/data/weknora/dev` 数据也已合并回根目录。
- 模型服务不使用这个目录。

### 5.3 目录核对

```bash
docker inspect WeKnora-postgres --format '{{ range .Mounts }}{{ .Source }} -> {{ .Destination }}{{ println }}{{ end }}'
docker inspect WeKnora-app --format '{{ range .Mounts }}{{ .Source }} -> {{ .Destination }}{{ println }}{{ end }}'
```

如果输出中出现 `/data/weknora/...`，说明业务栈挂载已经正确切到宿主机目录。
