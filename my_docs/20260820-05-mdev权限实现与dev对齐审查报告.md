# 20260820 mdev 权限实现与 dev 对齐审查报告

## 0. 报告说明

- **目标态**：`dev` 分支的"权限主线"实现（含组织权限 / KB 可见性 / Agent 可见性 / 超管跨租户 / KB 访问门控）。
- **目标分支**：`mdev`（当前工作区，含未提交改动）。
- **对比方法**：
  1. `git diff mdev dev -- <file>`（提交级）用于定位两分支差异面。
  2. `git diff dev -- <file>`（工作区级）用于核对手动改动 vs dev 后是否还有残余缺口。
  3. 仅关注**权限语义**（RBAC / 可见性 / 超管 / 组织 role / 访问门控），忽略上游功能分叉（数据库数据源、chat 流程、agent 建议问题 tag-scope、sandbox 配置、API key 平台作用域等）。
- **原则**：mdev 基于较新的 `upstream/main`，**不做整文件对齐**，只做"权限相关 hunk"的对齐；mdev 上游特性必须保留。

## 1. 结论总览

### 1.1 一句话结论

**Agent 侧的"超管识别 + 可见性字段 + 可见性归一化"已与 dev 基本齐平；但 KB 侧与运行时门控仍存在成片差异：KnowledgeBase 的创建/编辑/列表/API 权限校验链路、KBAccess/RBAC 接线、Agent visibility handler 接线、跨租户超管语义仍未对齐 dev。**

### 1.2 数据速览

| 类别 | 数量 | 说明 |
|---|---:|---|
| 已对齐主链路 | 不单独计数 | 见 §2（本节主要覆盖 agent / auth 主链路） |
| 待补齐核心文件（真实权限语义差异） | 至少 10 个后端/集成文件，另有 3 个 KB 前端初始化文件 | 见 §3 |
| dev 已移除、mdev 保留的上游特性（务必不动） | 5 处 | 见 §4 |
| 无实质差异（仅注释 / 排版 / 类型写法 / 文案） | 4 处 | 见 §5 |

### 1.3 关键风险

- 若直接 `git checkout dev -- <file>` 整文件覆盖这些待补齐文件，会**误删 mdev 的上游特性**（API Key 路由鉴权整套、KB API-Key allow-list、sandbox 配置注入、建议问题 tag-scope）。**必须按 hunk 手工对齐**。

### 7.2 运行时场景（浏览器 + curl）

以三个账号复测：
- **super_admin**：`IsSuperAdmin=true`（org_tree 管理员 API 设的），`IsSystemAdmin=false`。
- **space_admin**（组织树节点管理员）：某个 org 的 `OrgRoleAdmin`。
- **org_member**（普通 org 成员）：某个 org 的 `OrgRoleViewer`。
- **private_user**：无 org 归属。

| 场景 | 预期 |
|---|---|
| sa 创建 agent，visibility=org + org_id=X | 落库 `visibility=org, organization_id=X`；`/api/agents?tenant=...` 返回给 space_admin(org∈X 子树) 与 super_admin，不返回给 org_member(不在 X 子树) |
| sa 创建 KB，visibility=org + org_id=X | `/api/kb/{id}/documents` 对 space_admin(org∈X 子树) 200，对 org_member 403（这一步依赖 §3.1 A2 生效，否则当前 mdev 是 200） |
| sa 创建 KB，visibility=private | 只有 sa 与 tenant owner 可读写 |
| sa 创建 KB，visibility=global | 同租户全员可读，管理员可写 |
| space_admin 更新 sa 创建的 org-visible agent | 若 space_admin 是该 org 的 admin 且 agent 落在其管理域，允许；否则 403（依赖 §3.2 B4） |
| org_member `GET /api/agents/{id}` 命中一个 visibility=private 的 agent | 403（依赖 §3.2 B3） |
| 全局关闭 `EnableCrossTenantAccess`，super_admin 访问 `/api/platform/tenants` | 200（依赖 §3.3 C1 放宽后） |
| 同一 API 用 CanAccessAllTenants=true 但非 platform-privileged 的用户 | 403（仍需全局开关） |
